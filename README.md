# Axial-Compressor-Design
本MATLAB工具实现了多级轴流压缩机的热力计算功能，基于《轴流压缩机原理与气动设计》的理论框架。该工具可根据用户输入的工质参数、边界条件和设计参数，计算各级压缩过程的温度、压力、速度等关键参数，并输出压缩机整体性能指标。  
使用方法：matlab使用parameters_input作为数据输入和结果呈现，AxialCompressor为计算方法
